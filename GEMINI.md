## 2. Alokasi Model & Protokol Kuota (Anti-Quota Exhaustion)

| Kategori Beban Kerja | Cakupan Tugas di Codebase | Target Model | Alasan & Keunggulan |
| :--- | :--- | :--- | :--- |
| **Lookup, Search & Scan** | Cek file, grep simbol, scanning dokumen, cek status Basemind | **Gemini Flash-Lite / Flash** | Konsumsi kuota minimal, respon ultra-cepat. |
| **Penyusunan Konten & Artikel** | Penulisan artikel 3x sehari (05.30, 11.30, 19.00 WIB), SOP Anti-AI, microcopy | **Gemini Flash** | Bebas limit harian ketat, kualitas penulisan bahasa Indonesia sangat baik. |

| **Critical Build & Astro Deployment** | Modifikasi Astro config, script deployment VPS, zero-defect review | **Claude Sonnet** | Presisi tinggi mencegah kegagalan build pada remote server. |

### Protokol Batas Giliran Percakapan (*Turn Cap*):
* **Batas Maksimal**: Jika satu sesi percakapan mencapai **30–40 langkah (turns)**, agent **wajib** merekomendasikan slash command `/compact` atau menyarankan membuka sesi baru.
* **Alasan**: Riwayat percakapan panjang mengirim ulang puluhan ribu token mentah setiap turn (dapat membengkak hingga >70.000 input token per pesan tunggal) yang dapat langsung menguras kuota harian akun.
