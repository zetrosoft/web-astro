## n8n Queue Mode Architecture: Stable & Scalable

For production environments, running n8n in `queue mode` is highly recommended. This architecture separates the workflow execution process from the user interface, enhancing stability and scalability:

*   **PostgreSQL:** Used as the primary database to store n8n's workflow data, credentials, and configurations. PostgreSQL is a robust and proven relational database for production applications.
*   **Redis:** Functions as a queue broker and cache. Redis handles the queue of workflow execution tasks, ensuring that workflows are processed sequentially and efficiently, even under high load.

### 2. Install Docker & Docker Compose

Install Docker and Docker Compose, which will be used to manage the n8n, PostgreSQL, and Redis containers.

1.  **Install Docker:**
    ```bash
    sudo apt install docker.io -y
    sudo systemctl start docker
    sudo systemctl enable docker

    newgrp docker # Logout and login again or run this command
    ```
2.  **Install Docker Compose:**
    ```bash
    sudo apt install docker-compose -y
    ```

### 3. Configure Docker Compose for n8n, PostgreSQL, and Redis

Create a `docker-compose.yml` file to define your services.

1.  Create a directory for n8n and navigate into it:
    ```bash
    mkdir n8n-automation
    cd n8n-automation
    ```
2.  Create the `docker-compose.yml` file:
    ```bash
    nano docker-compose.yml
    ```
3.  Copy and paste the following configuration. **Be sure to replace `your-domain.com` with your actual domain or VPS IP, and substitute `N8N_POSTGRES_PASSWORD` and `N8N_BASIC_AUTH_PASSWORD` with strong passwords.**

    ```yaml
    version: '3.8'

    services:
      n8n:
        image: n8nio/n8n
        restart: always
        environment:
          DB_TYPE: postgresdb
          DB_POSTGRES_HOST: postgres
          DB_POSTGRES_PORT: 5432
          DB_POSTGRES_DATABASE: n8n
          DB_POSTGRES_USER: n8n_user
          DB_POSTGRES_PASSWORD: your_strong_postgres_password # Change this
          
          QUEUE_HEALTH_CHECK_ACTIVE: 'true'
          QUEUE_BULL_REDIS_HOST: redis
          QUEUE_BULL_REDIS_PORT: 6379

          N8N_HOST: your-domain.com # Replace with your domain or VPS IP
          N8N_PORT: 5678
          N8N_PROTOCOL: http # Use https if you set up a reverse proxy with SSL
          WEBHOOK_URL: http://your-domain.com:5678/ # Replace with your domain or VPS IP

          GENERIC_TIMEZONE: Asia/Jakarta # Adjust your timezone

          N8N_BASIC_AUTH_ACTIVE: 'true'
          N8N_BASIC_AUTH_USER: admin
          N8N_BASIC_AUTH_PASSWORD: your_strong_n8n_password # Change this

          NODE_ENV: production
          TZ: Asia/Jakarta
        volumes:
          - n8n_data:/home/node/.n8n
        ports:
          - "5678:5678"
        depends_on:
          - postgres
          - redis

      postgres:
        image: postgres:15
        restart: always
        environment:
          POSTGRES_DB: n8n
          POSTGRES_USER: n8n_user
          POSTGRES_PASSWORD: your_strong_postgres_password # Must match DB_POSTGRES_PASSWORD in n8n
        volumes:
          - postgres_data:/var/lib/postgresql/data

      redis:
        image: redis:7
        restart: always
        volumes:
          - redis_data:/data

    volumes:
      n8n_data:
      postgres_data:
      redis_data:
    ```

### 4. Run n8n

Save the `docker-compose.yml` file (Ctrl+X, Y, Enter) and start the Docker Compose services:

```bash
docker compose up -d
```

Verify that all containers are running correctly:

```bash
docker compose ps
```

Now you can access the n8n interface via your browser at `http://your-domain.com:5678/` (replace `your-domain.com` with your domain or VPS IP). You will be prompted to enter the basic auth credentials you set up.
